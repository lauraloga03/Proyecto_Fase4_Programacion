# Sistema de Gestión de Reservas - Software FJ

## Descripción
Este proyecto consiste en el desarrollo de un sistema de gestión de clientes, servicios y reservas utilizando programación orientada a objetos en Python. El sistema cuenta con una interfaz gráfica que permite la interacción del usuario de manera sencilla e intuitiva.

## Funcionalidades
- Registro de clientes
- Creación de reservas
- Selección de servicios (Sala, Equipo, Asesoría)
- Cancelación de reservas
- Visualización de historial
- Interfaz gráfica interactiva
- Manejo de excepciones
- Registro de errores en archivo de logs

## Tecnologías utilizadas
- Python
- Tkinter

## Ejecución del sistema
Para ejecutar el programa, utilizar el siguiente comando en la terminal:
python sistema_reservas_fj.py
